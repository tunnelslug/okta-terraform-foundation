# How okta-terraform-foundation works

Modular multi-stack Okta Terraform: identity, apps, policies, authz, governance.
OIDC-only auth, split state (S3/GCS), import path for existing orgs, CI scaffolds.

Full documentation lives in `docs/` in this repository (OWNERSHIP, AUTH, IMPORT, ADOPTING, APP_TRACKING, CI_GITHUB, CI_AWS).
